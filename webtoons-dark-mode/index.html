Webtoons Dark Mode - Privacy Policy

Last updated: September 19, 2026

Overview

Webtoons Dark Mode is a Chrome extension that restyles the webtoons.com website in dark colors. It collects no data at all.

Data collected

None. The extension has no accounts, no analytics, no tracking, no advertising identifiers, no crash reporting, and no storage. It does not read, save or transmit the pages you visit, what you read, or anything you type.

What the extension does on the page

It runs only on webtoons.com. There it reads the stylesheets the website itself loads, calculates dark versions of their colors, and adds those colors to the page. Everything happens locally in your browser.

Network requests

The extension makes one kind of request: it re-reads the comments stylesheet from ssl.pstatic.net, the same file webtoons.com already loads for its comments section, so its colors can be darkened too. No data about you is sent with it, and no request is made to any server belonging to the developer.

Permissions

The extension requests access to *.webtoons.com only, in order to apply its styling there. It requests no other permissions.

Children's privacy

The extension does not knowingly collect any data from anyone, including children.
